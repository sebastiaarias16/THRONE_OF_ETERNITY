# ♛ THRONE OF ETERNITY — SITIO WEB OFICIAL

> *"Un mundo forjado por fuerzas primordiales. Civilizaciones separadas por guerras, antiguas alianzas y secretos olvidados. Cinco mil años después de la Ruptura, Elyndor se encuentra ante un nuevo destino."*
> 
> **"THE WORLD WILL REMEMBER YOUR CHOICES."**

Sitio web oficial interactivo para **THRONE OF ETERNITY**, un videojuego RPG de fantasía oscura y mundo abierto desarrollado de manera independiente sobre **Unreal Engine 5.8.4**.

## ✦ 4. INSTRUCCIONES PARA EJECUTAR EN LOCAL

### Requisitos previos:
- Node.js versión 18 o superior.
- npm (o pnpm / yarn).

### Pasos:

1. **Instalar dependencias:**
   ```bash
   npm install
   ```

2. **Iniciar servidor de desarrollo:**
   ```bash
   npm run dev
   ```
   Abre [http://localhost:3000](http://localhost:3000) en tu navegador para interactuar con el sitio web.

3. **Compilar para producción:**
   ```bash
   npm run build
   ```
   Genera la carpeta optimizada `dist/` con JavaScript minificado, CSS purgado y tipados validados.

4. **Previsualizar la compilación de producción:**
   ```bash
   npm run preview
   ```

## ✦ 5. DESPLIEGUE EN VERCEL

El proyecto incluye el archivo de configuración `vercel.json` listo para producción:

### Opción A — Mediante Vercel CLI:
```bash
npm install -g vercel
vercel
```

### Opción B — Conectando con GitHub:
1. Sube este repositorio a tu cuenta de GitHub.
2. Inicia sesión en [Vercel](https://vercel.com/) e importa el repositorio `THRONE_OF_ETERNITY`.
3. Vercel detectará automáticamente **Vite**:
   - **Framework Preset:** `Vite`
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
4. Haz clic en **Deploy**. El sitio quedará desplegado con certificado SSL automático y CDN global de alto rendimiento.

## ✦ 6. CÓMO CONECTAR UN PROVEEDOR DE NEWSLETTER

El formulario de suscripción (`src/components/sections/CommunitySection.tsx`) almacena actualmente los correos de manera simulada y segura en `localStorage`.

Para vincularlo a un proveedor real:
- **Resend:** Crea una Serverless Function o API Route en `/api/subscribe` que reciba `{ email }` y llame a `resend.contacts.create(...)`.
- **Mailchimp:** Sustituye el handler `handleSubscribe` para enviar una petición `POST` al endpoint de lista de Mailchimp con tu API Key en variables de entorno (`VITE_MAILCHIMP_ENDPOINT`).
- **ConvertKit / Buttondown:** Puedes apuntar directamente la acción del formulario al webhook URL provisto por la plataforma.
